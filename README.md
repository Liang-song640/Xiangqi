# Xiangqi · 中国象棋

大一 Java 课程项目：基于 Swing 的中国象棋小游戏，带用户系统、游戏存档与多媒体素材。

## 功能特性

- **完整象棋规则**：帅/将、仕/士、相/象、马、车、炮、兵/卒全部棋子的合法走法判断与吃子
- **用户系统**：注册 / 登录 / 游客模式（用户数据存于 `data/users.dat`）
- **游戏存档**：登录用户可保存、读取、删除对局存档（存于 `saves/`，序列化格式）
- **音乐系统**：两首背景音乐可切换、音量可调、吃子音效
- **11 种背景主题**：默认 + 黑色、绯红、绿色、浅蓝、黄色、春意、橙色、紫色、玫红、池水
- 回合提示、上一步操作提示、重新开始、退出登录

## 目录结构

| 路径 | 说明 |
|---|---|
| `src/main/java/edu/sustech/xiangqi/` | 源码（`model/` 棋子与游戏逻辑，`ui/` 棋盘界面） |
| `src/Music/` | 背景音乐与音效 |
| `src/Background/` | 10 张棋盘背景图 |
| `pom.xml` | Maven 配置（Java 8） |

## 运行方法

环境要求：JDK 8+。

- **IntelliJ IDEA**：直接打开项目，运行 `XiangqiApplication` 的 `main` 方法
- **命令行**：
  ```bash
  mvn compile
  java -cp target/classes edu.sustech.xiangqi.XiangqiApplication
  ```

> 注意：程序以相对路径 `./src/Music/...`、`./src/Background/...` 加载素材，**运行时的工作目录必须是项目根目录**。
